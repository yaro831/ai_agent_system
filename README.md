

מערכת חדשנית לניהול סוכני בינה מלאכותית מבוזרים המתקשרים ביניהם באמצעות פרוטוקול A2A (Agent-to-Agent). כל סוכן מתמחה בתחום ספציפי ומשתמש ב-API של OpenAI לביצוע המשימות שלו.

## יתרונות המערכת

- **מודולריות**: הוספה והסרה של סוכנים בקלות
- **התמחות**: כל סוכן מומחה בתחום ספציפי
- **יעילות**: תקשורת מובנית באמצעות JSON
- **סקלביליות**: מערכת שגדלה בהתאם לצרכים
- **שקיפות**: תיעוד מלא של תהליכי קבלת החלטות

## דרישות מערכת

- Python 3.8+
- OpenAI API key
- MongoDB (או מסד נתונים אחר לבחירתך)
- Redis (אופציונלי לניהול תורים)

## התקנה

1. שכפל את המאגר:
```
git clone https://github.com/your-username/ai-agent-system.git
cd ai-agent-system
```

2. התקן את התלויות:
```
pip install -r requirements.txt
```

3. צור קובץ `.env` עם משתני הסביבה הנדרשים (ראה `.env.example`).

4. הפעל את האפליקציה:
```
python app.py
```

## שימוש בסיסי

```python
from core.agent_manager import AgentManager

# יצירת מנהל סוכנים
manager = AgentManager()

# הפעלת משימה
result = manager.execute_task("פיתוח אסטרטגיית שיווק למוצר החדש")
print(result)
```

## תהליך עבודה טיפוסי

1. **קליטת משימה**: המערכת מקבלת משימה חדשה
2. **ניתוב משימה**: מנהל הסוכנים מחליט לאיזה סוכן להעביר את המשימה
3. **ביצוע**: הסוכן הנבחר מבצע את המשימה, תוך כדי התייעצות עם סוכנים אחרים במידת הצורך
4. **דיווח**: התוצאות מועברות חזרה למשתמש
